# PNR Journal GGS (Громкоговорящая и диспетчерская связь)

Автономный генератор журнала производства пусконаладочных работ (ПНР) для систем оперативно-диспетчерской и громкоговорящей связи (СОДС и ГГС Armtel).

Генерирует готовые исполнительные документы в формате **Markdown** с калиброванной типографикой ГОСТ/ЕСКД (14pt текст, 12pt таблицы, 10pt акустические замеры), встроенными Base64-ассетами (векторные логотипы, подписи, шрифты) и возможностью прямой печати в **PDF**.

---

## Возможности системы

- 📋 **Ведомость оборудования и автоматическая классификация**: подсчет центральных коммутаторов, модулей E1/SIP/NCU, пультов DIS, постов DW, громкоговорителей (AR-25, CP-66(T), B-406(T)) и установок бесперебойного питания (ИБП).
- ✅ **27 чек-листов индивидуальных испытаний**: автоматическая привязка нормативных проверок и заводских параметров по каждому типу оборудования.
- ⚡ **Протокол испытаний ИБП (Приложение В)**: расчет времени автономной работы под нагрузкой 1740 Вт (ШТИЛЬ PS48-0080-2U с 4 АКБ по 40 А·ч) с таблицей пошагового разряда и восстановления.
- 🔊 **Протокол акустических измерений (Приложение Г)**: таблица на 49 контролируемых точек с замерами фонового шума, сигналов оповещения, подтверждением $\Delta L \ge 15\text{ дБА}$ и 100% разборчивости речи.
- 📜 **Акты приемки и автономных испытаний (Приложения Ж и И)**: юридически выверенные формы с факсимиле подписей.
- 🎨 **Инженерная типографика**: подключение шрифта *PF Din Text Cond Pro*, выравнивание по ширине, отступ первой строки 1.25 см, выравнивание 1-го столбца таблиц влево.

## Установка и быстрый старт

### 1. Установка зависимостей
Требуется Python 3.10+:
```bash
pip install -r requirements.txt
```

### 2. Запуск генерации журнала ПНР
```bash
python main_md.py render-ggs --project 12006-81-0600-СС1.2
```
*Результат будет сохранен в папку `output/Журнал_ПНР_12006-81-0600-СС1.2.md`.*

Или через универсальный вызов:
```bash
python main_md.py render --project 12006-81-0600-СС1.2
```

### 3. Запуск тестов
```bash
python -m unittest discover tests
```

---

## Экспорт в PDF

1. Откройте сгенерированный файл `output/Журнал_ПНР_12006-81-0600-СС1.2.md` в VS Code.
2. Установите расширение **Markdown-PDF** (`yzane.markdown-pdf`).
3. Нажмите `F1` $\rightarrow$ `Markdown PDF: Export (pdf)`.
